# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussion on the work and not on the
person, and accept that maintainers may edit or remove contributions and comments that do
not meet that standard.

Report unacceptable behavior to the maintainers through a private GitHub security advisory
on this repository (Security tab, Report a vulnerability). Reports are kept confidential.
